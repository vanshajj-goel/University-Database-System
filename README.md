# University Database Management System

A relational database management system designed to manage academic
and administrative operations of a university.

## Features

- Student management
- Faculty management
- Department management
- Course and subject management
- Hostel management
- Student hostel allocation
- Faculty teaching allocation
- Student results and grades
- Grade payment management
- HOD and Dean management
- Directorate management
- SQL queries
- PL/SQL procedures

## Technologies

- Oracle SQL
- PL/SQL
- Relational Database Management System
